# Known non-conforming launch-evidence directories, baselined 2026-07-27.
# Format: <matrix section label>/<bundle directory name> # <reason>
#
# WHY THIS FILE EXISTS
#
# scripts/probe_launch_evidence_freshness.sh reports two diagnostic categories
# for directories it cannot accept as evidence bundles:
#
#   rejected  — a well-named bundle missing or emptying its section's required
#               completion files. For section 5 these are preserved NONGREEN HA
#               soak runs: the soak did not complete, so the completion files
#               are legitimately absent or zero-length.
#   malformed — a directory whose name does not match <UTCTIMESTAMP>_<name>.
#               The four section 6 entries predate that convention.
#
# In both cases the probe does the RIGHT thing: it excludes the directory and
# still resolves a valid most-recent-accepted bundle for the section
# (missing=0 missing_section=0 unparseable=0). These are historical artifacts of
# a real evidence corpus, not damage. Curating them away would destroy audit
# history — a failed HA soak is evidence, and deleting it to make a gate green
# is the exact dishonesty this project's gates exist to prevent.
#
# Before this baseline existed, gate_launch_evidence_freshness_contract failed
# hard whenever rejected_bundles>0 or malformed_names>0. Since those counts can
# never reach zero without destroying history, the gate was PERMANENTLY RED on
# main and could not distinguish "evidence is old" from "evidence is malformed"
# — which is the entire point of the instrument.
#
# HOW THIS STAYS A REAL GUARD
#
# The gate compares the probe's live diagnostic set against this file exactly,
# in BOTH directions:
#
#   - A diagnostic NOT listed here fails the gate. New corpus rot — a bundle
#     written with a bad name, or a completion-file regression in a bundle
#     shape — is caught on the first run, which is the failure mode worth
#     catching.
#   - A line here that the probe NO LONGER reports also fails the gate. If a
#     bundle is curated or retired, its line is deleted in the same commit;
#     that is the repo's standing "update pointers atomically" rule, and it
#     stops this registry from silently rotting into an unconditional pass.
#
# So this file cannot be used to shadow a real defect: it can only ever
# describe the exact 18 directories enumerated below.
#
# Live specimen proving the guard can fail: create any directory named
# `docs/runbooks/evidence/launch-rc-runs/not_a_bundle` and re-run the gate; the
# probe reports it malformed, it is absent from this file, and the gate exits
# non-zero.
#
# Do NOT add a line here to silence a bundle you just wrote. New evidence must
# conform to <UTCTIMESTAMP>_<name> and carry its section's completion files.
# This baseline is closed to the 2026-05 corpus and should only ever shrink.
